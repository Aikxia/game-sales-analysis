# Data

The raw dataset is `data/raw/vgsales.csv`.

Source: [Video Game Sales on Kaggle](https://www.kaggle.com/datasets/gregorut/videogamesales)

The CSV contains 16,598 records and the following columns:

- `Rank`
- `Name`
- `Platform`
- `Year`
- `Genre`
- `Publisher`
- `NA_Sales`
- `EU_Sales`
- `JP_Sales`
- `Other_Sales`
- `Global_Sales`

Consult the Kaggle dataset page for the current licence and citation details.
